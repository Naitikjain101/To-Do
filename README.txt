NOCTURNE - To-Do App with Login
================================

HOW TO RUN
1. Unzip this folder (keep the css and js folders where they are).
2. Double-click login.html to open it in your browser (Chrome, Edge, Firefox).
3. Click "Sign up", create a username and password.
4. You land on the to-do app. Add tasks and enjoy.

FILES
login.html   - login / sign-up page
index.html   - the to-do app (needs login)
css/style.css - all styling, shared by both pages
js/login.js  - login and sign-up logic
js/app.js    - to-do logic (add, edit, delete, filter, progress)

NOTES
- Data is saved in your browser (localStorage), so it stays after refresh.
- Demo only: passwords are not secure. A real app needs a server.
- Title font loads from Google Fonts (internet needed for it; fallback font otherwise).
